# README 素材说明

把截图/动图放到本目录（`docs/media/`），README 会引用这些文件。

## 文件名约定

- `preview-pane-code.png`：资源管理器预览窗格 - 代码
- `preview-pane-archive.png`：资源管理器预览窗格 - 压缩包
- `preview-pane-image.png`：资源管理器预览窗格 - 图片
- `tray-menu.png`：托盘右键菜单
- `previewall-demo.gif`：一分钟演示动图（可选但推荐）

## 建议

- 尽量包含：被选中的文件、右侧预览窗格、以及能看出文件类型的细节。
- 截图建议使用 PNG；动图建议 5~10 秒，文件大小尽量控制在 10MB 内。
