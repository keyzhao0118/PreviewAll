# Preview All

> 开发者入口：[本地构建、依赖与工程结构](docs/development.md)。本文列出当前代码实际接入的功能。

**不用打开文件，选中就能预览。**

Preview All 是一款 Windows 资源管理器预览窗格扩展。目前支持常见图片、ZIP/RAR/7z 压缩包和 Markdown 文件。它不提供缩略图，也尚未接入代码文件预览。

三种预览共用同一标题栏：左侧显示 PreviewAll 图标和文件名，右侧按钮调用 Windows 文件关联打开原文件。

## 它能预览什么？

### 🖼️ 图片

在预览窗格中查看图片，初始适应窗口；可用鼠标滚轮缩放并拖动图片。

支持扩展名：`.png`、`.jpg`、`.jpeg`、`.tif`、`.tiff`、`.bmp`、`.webp`、`.ico`、`.svg`、`.gif`

<!-- 📸 TODO: 在此插入图片预览效果的截图 -->

### 📦 压缩包

无需解压即可查看压缩包内的目录树；加密压缩包可在预览中输入密码。

支持格式：ZIP、RAR、7z

<!-- 📸 TODO: 在此插入压缩包预览效果的截图 -->

### 📝 Markdown

渲染 Markdown 内容。

支持扩展名：`.md`、`.markdown`。文件大小上限为 8 MiB。

<!-- 📸 TODO: 在此插入 Markdown 预览效果截图 -->

图片预览支持滚轮缩放和拖动；压缩包预览显示可展开、收起的目录树。当前不支持代码文件预览、PDF、字体预览或 Explorer 缩略图。

## 快速上手

### 第 1 步：安装

前往 [Releases 页面](../../releases) 下载最新的安装包（`PreviewAll_Setup_x.x.x.exe`），双击运行，按照提示完成安装。安装过程会自动注册所需的系统组件，无需额外操作。

<!-- 📸 TODO: 在此插入安装向导截图 -->

### 第 2 步：启动

安装器默认会启动 Preview All。之后也可以从开始菜单或桌面快捷方式手动启动。

### 第 3 步：选择预览类型

在任务栏托盘区域找到 Preview All 图标，右键打开菜单，勾选你需要的预览类型：

- **Preview Image** — 图片预览
- **Preview Archive** — 压缩包预览
- **Preview Markdown** — Markdown 预览

勾选类别会为该类别支持的扩展名启用预览；设置保存在本机。

### 第 4 步：开始使用

在资源管理器中按 `Alt + P` 打开预览窗格，然后单击选中任意受支持的文件，右侧就会显示预览内容。

## 日常使用小贴士

| 操作 | 方法 |
|------|------|
| 打开/关闭预览窗格 | 在资源管理器中按 `Alt + P` |
| 切换预览类型 | 右键点击托盘图标，勾选或取消勾选 |
| 退出程序 | 右键托盘图标 → Exit |

- Preview All 在后台托盘运行时，预览功能才会生效。
- 你的勾选设置会自动保存，下次启动无需重新配置。
- 当前实现会在 Preview All 正常退出时移除已启用的扩展名预览绑定；重新启动时会按保存的勾选状态恢复。
- 程序只会运行一个实例，不用担心重复启动。

## 常见问题

<details>
<summary><b>预览窗格一直空白，什么都不显示？</b></summary>

请按顺序检查：

1. 资源管理器是否已打开预览窗格（按 `Alt + P`）
2. Preview All 是否仍在托盘运行（查看任务栏右下角）
3. 托盘菜单里对应的预览类型是否已勾选
4. 尝试关闭并重新打开资源管理器窗口

</details>

<details>
<summary><b>安装时为什么需要管理员权限？</b></summary>

安装包需要将 COM 预览处理程序注册到系统（写入 HKLM 和 HKCU）。安装后，勾选托盘菜单中的类别才会为相应扩展名启用 Preview All。注册状态有效时，日常运行通常不需要管理员权限。

</details>

<details>
<summary><b>退出程序后预览就不工作了？</b></summary>

这是正常的。Preview All 的预览内容由托盘程序实时提供，退出程序后预览自然会停止。重新启动 `PreviewAll.exe` 即可恢复。

</details>

<details>
<summary><b>如何卸载？</b></summary>

通过 Windows 标准方式卸载即可：打开 **设置 → 应用 → 已安装的应用**，找到 Preview All，点击 **卸载**。安装器会删除程序文件及其 COM 注册项；扩展名预览绑定由托盘程序在正常退出时清理。

</details>
