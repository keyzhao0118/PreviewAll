# Preview All

**不用打开文件，选中就能预览。**

Preview All 是一款 Windows 资源管理器增强工具，让你在资源管理器的预览窗格中直接查看图片、压缩包、代码等 60+ 种文件——选中即可预览，无需打开任何软件。

## 它能预览什么？

### 🖼️ 图片

直接查看图片内容，自动适应窗口大小。

支持格式：PNG、JPEG、BMP、WebP、SVG、GIF、TIFF、ICO

## 快速上手

### 第 1 步：安装

前往 [Releases 页面](../../releases) 下载最新的安装包（`PreviewAll_Setup_x.x.x.exe`），双击运行，按照提示完成安装。安装过程会自动注册所需的系统组件，无需额外操作。

<!-- 📸 TODO: 在此插入安装向导截图 -->

### 第 2 步：启动

安装完成后，Preview All 会自动启动。你也可以从开始菜单或桌面快捷方式手动启动。

### 第 3 步：选择预览类型

在任务栏托盘区域找到 Preview All 图标，右键打开菜单，勾选你需要的预览类型：

- **Preview Image** — 图片预览
- **Preview Archive** — 压缩包预览
- **Preview Code** — 代码/文本预览

<!-- 📸 TODO: 在此插入托盘菜单的截图，标注三个勾选项 -->

### 第 4 步：开始使用

在资源管理器中按 `Alt + P` 打开预览窗格，然后单击选中任意受支持的文件，右侧就会显示预览内容。

## 日常使用小贴士

| 操作 | 方法 |
|------|------|
| 打开/关闭预览窗格 | 在资源管理器中按 `Alt + P` |
| 切换预览类型 | 右键点击托盘图标，勾选或取消勾选 |
| 退出程序 | 右键托盘图标 → Exit |

- Preview All 在后台托盘运行时，预览功能才会生效。
- 你的勾选设置会自动保存，下次启动无需重新配置。
- 程序只会运行一个实例，不用担心重复启动。

## 常见问题

<details>
<summary><b>预览窗格一直空白，什么都不显示？</b></summary>

请按顺序检查：

1. 资源管理器是否已打开预览窗格（按 `Alt + P`）
2. Preview All 是否仍在托盘运行（查看任务栏右下角）
3. 托盘菜单里对应的预览类型是否已勾选
4. 尝试关闭并重新打开资源管理器窗口

</details>

<details>
<summary><b>安装时为什么需要管理员权限？</b></summary>

安装包需要将预览组件注册到系统中（写入注册表），这样资源管理器才知道用 Preview All 来预览对应的文件。这个过程在安装时自动完成，程序日常运行不需要管理员权限。

</details>

<details>
<summary><b>退出程序后预览就不工作了？</b></summary>

这是正常的。Preview All 的预览内容由托盘程序实时提供，退出程序后预览自然会停止。重新启动 `PreviewAll.exe` 即可恢复。

</details>

<details>
<summary><b>如何卸载？</b></summary>

通过 Windows 标准方式卸载即可：打开 **设置 → 应用 → 已安装的应用**，找到 Preview All，点击 **卸载**。卸载程序会自动清理所有注册信息和程序文件。

</details>
